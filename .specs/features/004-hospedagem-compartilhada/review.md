## Findings

- **R004-01 — Empty installer path assignments in `.env` silently select a fallback.** **Status:** open. **Evidence:** `tools/deploy-shared-hosting.sh:18-46` tracks `found_set` only inside `read_dotenv_path()` but returns only the value. `configured_value()` at lines 49-60 therefore cannot distinguish an absent key from `PHP_BIN=`, `GIT_BIN=`, or `COMPOSER_BIN=`. The branches at lines 86-126 validate a file value only when it is nonempty, so an explicitly empty file assignment falls through to PATH or the tracked PHAR. This diverges from S004-06 and T004-02, which require any configured invalid path to fail rather than silently select another executable. **Impact:** an operator typo can deploy with an unintended PHP, Git, or Composer entry point while the command reports success. **Correction:** preserve both presence and value when reading each installer key and send every present file assignment, including an empty one, through `validate_configured_path()`; retain process-over-file precedence. **Acceptance and test:** isolated installer tests set each of the three `.env` keys to an empty value while a valid fallback exists, assert nonzero exit and the named configuration error, and assert that the fallback executable and all deployment steps were not invoked.
- **R004-02 — T004-02 is checked without its originally required installer and migration matrix.** **Status:** closed under explicitly authorized reduced scope. **Evidence:** repository search found no automated test referencing `deploy-shared-hosting.sh`, `PHP_BIN`, `GIT_BIN`, or `COMPOSER_BIN`; the only new integration test covers dotenv web startup. The Plan at T004-02 requested temporary-repository/substitute-executable coverage and disposable-database privilege cases. In place of that matrix, the current Compose environment verified the non-`main` guard, the pinned-PHAR production install, an idempotent production migration as `app@%`, and finally one complete successful installer invocation from clean local `main` through remote pull, Composer install, and Phinx migration. **Impact:** executable-selection failures, other Git failure boundaries, initial migration, and insufficient-privilege behavior remain without automated regression coverage. **Decision:** on 2026-10-17, Paulo Bezerra explicitly authorized dispensing with the simulated-host matrix and accepting the current Compose execution as the practical gate. No further Code execution is required for this finding under that exception; future failures in the omitted cases are the residual risk of the authorized reduction.
